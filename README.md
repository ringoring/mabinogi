# 리비 길드 · 월요일 정기 콘텐츠 스케줄러

길드원이 캐릭터명·참석여부·시간·전투력을 입력해 **신청/투표**하고,
마감 후 **9시 정시 / 9시 이후 / 미참석 / 미투표** 로 분류하며,
탱·힐 분산 + 전투력 균형으로 **4인 파티를 자동 구성**하는 웹사이트입니다.

**두 가지 배포 방식**이 있습니다 (상황에 맞게 택1):

| 방식 | 특징 | 추천 상황 |
|------|------|-----------|
| **A. Apps Script 내장앱** (`apps-script/`) | 시트 1개에 화면+데이터가 다 들어감. **웹앱 URL 하나가 곧 사이트.** 접속 시 구글 로그인 1회. | 배포 계정에 "모든 사용자(익명)" 옵션이 **없을 때**(새 계정 등) — `Google 계정이 있는 모든 사용자`로도 동작 |
| **B. GitHub Pages + 구글 시트** (`index.html`+`js/`) | 정적 사이트가 Apps Script 웹앱 API를 호출. 주소 깔끔, 로그인 불필요. | 배포 계정에 **"모든 사용자(익명)"** 옵션이 있을 때 |

- **저장소:** 구글 시트 (무료, 유저 가입/설치 불필요)
- **빌드 도구 없음** — 순수 HTML/CSS/JS

## 📂 구조

```
■ 방식 A — Apps Script 내장앱 (시트 1개로 끝)
apps-script/Code.gs     백엔드 + 화면 서빙 (doGet) + 데이터 API
apps-script/index.html  화면 골격 (styles/js 를 include)
apps-script/styles.html 스타일 (<style>)
apps-script/js.html     파티 로직 + UI 로직 (google.script.run 으로 시트 호출)

■ 방식 B — GitHub Pages 정적 사이트
index.html              메인 페이지
css/styles.css          스타일
js/config.js            ⚙️ 설정 (구글 시트 URL, 길드명, 마감시간 등) ← 주로 여기만 수정
js/party.js             파티 자동 분배 로직 (핵심 알고리즘)
js/api.js               백엔드 통신 (구글 시트 / 데모 모드 자동 전환)
js/app.js               화면/이벤트 로직

■ 공통
data/길드원_명단_샘플.csv  명단 양식 예시
tests/party.test.js     파티 분배 테스트  (npm test)
```

## 🚀 빠른 시작

### 0. 바로 미리보기 (데모 모드)
`js/config.js` 의 `APPS_SCRIPT_URL` 이 비어 있으면 **데모 모드**(브라우저 저장)로 동작합니다.
로컬에서 열어 화면/기능을 바로 확인할 수 있습니다.

```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> 데모 모드는 **본인 브라우저에만** 저장됩니다. 여러 사람이 공유하려면 아래 구글 시트 연동을 하세요.

## 🅰️ 방식 A — Apps Script 내장앱 (추천: 계정에 "모든 사용자" 옵션이 없을 때)

> 새로 만든 개인 구글 계정은 보안상 **"모든 사용자(익명)"** 배포 옵션이 한동안 숨겨져 있습니다.
> 그 경우 정적 사이트(방식 B)는 익명 요청이 막혀 동작하지 않습니다.
> 이 방식은 사이트를 Apps Script 가 직접 띄워, **`Google 계정이 있는 모든 사용자`** 옵션으로도 동작합니다.

### 1. 구글 시트 + 탭 3개 만들기
아래 [공통: 구글 시트 만들기](#1-구글-시트-만들기) 와 동일하게 `길드원` / `설정` / `투표` 탭을 준비합니다.

### 2. Apps Script 에 파일 4개 만들기
1. 시트 메뉴 **확장 프로그램 → Apps Script**
2. 좌측 파일 목록에서 다음을 만들고 내용을 그대로 붙여넣기:
   - `Code.gs` ← `apps-script/Code.gs`
   - `index.html` (＋ → **HTML**) ← `apps-script/index.html`
   - `styles.html` (＋ → **HTML**) ← `apps-script/styles.html`
   - `js.html` (＋ → **HTML**) ← `apps-script/js.html`
   > ⚠️ HTML 파일 이름은 확장자 빼고 **`index` / `styles` / `js`** 로 정확히 (Code.gs 가 그 이름으로 찾음)
3. (권장) ⚙️ 프로젝트 설정 → 시간대 **Asia/Seoul**

### 3. 웹앱 배포
1. 우상단 **배포 → 새 배포** → 유형: **웹 앱**
2. 실행: **나** / 액세스: **`Google 계정이 있는 모든 사용자`** → **배포** → 권한 승인
3. 나온 **웹 앱 URL**(`.../exec`) 이 **곧 사이트 주소**입니다. 길드원에게 그대로 공유하세요.
   - 길드원은 접속 시 구글 계정으로 **1회 로그인**하면 바로 사용 가능합니다.

> 코드 수정 후 재배포: **배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포** (URL 유지)

## 🅱️ 방식 B — GitHub Pages + 구글 시트 (계정에 "모든 사용자" 옵션이 있을 때)

### 1. 구글 시트 만들기
새 구글 시트를 만들고 아래 **탭 3개**를 추가합니다 (탭 이름 정확히):

**① `길드원`** — 길드원 명단 (관리자가 미리 등록)

| 캐릭터명 | 클래스 |
|---------|--------|
| 아르베드 | 전사 |
| 티르코네일 | 힐러 |
| … | … |

> `data/길드원_명단_샘플.csv` 를 그대로 가져와도 됩니다.
> **클래스 표기**는 아래 계열 표를 따르세요. 표에 없는 클래스는 모두 "딜러"로 처리됩니다.

**② `설정`**

| 키 | 값 |
|------|------|
| 기본시간 | 21:00 |
| 마감시간 | 21:00 |

**③ `투표`** — 비워두세요(헤더는 스크립트가 자동 생성). 직접 만들 경우 헤더:
`주차 | 캐릭터명 | 참석여부 | 시간 | 전투력 | 업데이트시각`

### 2. Apps Script 배포
1. 시트 상단 메뉴 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 **전부 붙여넣기**
3. (권장) ⚙️ 프로젝트 설정 → 시간대 **Asia/Seoul**
4. 우상단 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 실행 권한: **나(본인)**
   - 액세스 권한: **모든 사용자**
   - **배포** 클릭 → 권한 승인
5. 표시된 **웹 앱 URL**(`https://script.google.com/macros/s/..../exec`)을 복사

### 3. 사이트에 URL 연결
`js/config.js` 를 열어 붙여넣기:

```js
APPS_SCRIPT_URL: 'https://script.google.com/macros/s/..../exec',
```

이제 사이트가 구글 시트와 실시간으로 연동됩니다. (모두가 같은 데이터를 봅니다)

> 💡 코드 수정 후 재배포할 땐 **배포 → 배포 관리 → 기존 배포 편집(연필) → 버전: 새 버전 → 배포**.
> "새 배포"를 또 만들면 URL이 바뀌니 주의하세요.

## 🌐 GitHub Pages 배포
1. 이 저장소를 GitHub에 푸시 (이미 푸시되어 있음)
2. 저장소 **Settings → Pages**
3. **Source: Deploy from a branch**, Branch: `main`(또는 배포 브랜치) `/ (root)` → Save
4. 잠시 후 `https://<사용자명>.github.io/mabinogi/` 에서 접속

## ⚙️ 자주 바꾸는 설정 (`js/config.js`)

| 항목 | 설명 |
|------|------|
| `APPS_SCRIPT_URL` | 구글 시트 웹앱 URL (비우면 데모 모드) |
| `GUILD_NAME` / `CONTENT_TITLE` | 화면 상단 제목 |
| `DEFAULT_TIME` | 정시 기준 (이 시간 참석 = "9시 참석") |
| `DEADLINE_TIME` | 자동 마감 시각 (해당 주 월요일의 이 시각 지나면 마감) |
| `PARTY_SIZE` | 파티 인원 (기본 4) |

> 시트 연동 시 `기본시간`·`마감시간`은 **시트의 `설정` 탭 값이 우선** 적용됩니다.

## 🧩 파티 분배 규칙

**계열 구분**

| 계열 | 클래스 |
|------|--------|
| 🛡 탱커 | 전사, 빙결술사, 기사 |
| 💚 힐러 | 힐러, 사제, 음유시인, 수도사 |
| ⚔ 딜러 | 그 외 전부 |

**분배 우선순위**
1. 파티당 **탱커 1 + 힐러 1** 우선 구성
2. 부족하면 **둘 중 한 계열이라도** 들어가도록
3. 그래도 모자라면 탱/힐이 **여러 파티에 분산**되도록 (한 파티에 몰리지 않게)
4. 그 위에서 **파티별 전투력 합이 비슷하도록** 균형 분배
5. 탱/힐이 없는 파티는 화면에 **`탱 없음 / 힐 없음`** 경고 표시

`전투력` 균형이나 계열을 바꾸려면 `js/party.js` 상단의 `TANK_CLASSES`/`HEAL_CLASSES` 만 수정하면 됩니다.

## ❓ 문제 해결

- **투표가 저장 안 돼요 / CORS 오류** → Apps Script 배포 시 액세스가 **"모든 사용자"** 인지 확인하세요.
- **마감 시간이 이상해요** → Apps Script 프로젝트 시간대를 **Asia/Seoul** 로 설정했는지 확인.
- **클래스가 딜러로 나와요** → 시트 `길드원` 탭의 클래스 표기가 위 계열 표와 정확히 일치하는지 확인.
- **새 주가 안 넘어가요** → "이번 주 월요일"은 자동 계산됩니다(오늘이 월요일이면 오늘, 아니면 다가오는 월요일). 주가 바뀌면 투표는 자동으로 새로 시작됩니다.
