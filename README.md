# 리비 길드 · 월요일 정기 콘텐츠 스케줄러

길드원이 캐릭터명·참석여부·시간·전투력을 입력해 **신청/투표**하고,
마감 후 **9시 정시 / 9시 이후 / 미참석 / 미투표** 로 분류하며,
탱·힐 분산 + 전투력 균형으로 **4인 파티를 자동 구성**하는 웹사이트입니다.

- **호스팅:** GitHub Pages (정적)
- **저장소:** 구글 시트 (Apps Script 웹앱 경유 — 무료, 유저 가입/설치 불필요)
- **빌드 도구 없음** — 순수 HTML/CSS/JS

---

## 📂 구조

```
index.html              메인 페이지
css/styles.css          스타일

js/party.js             파티 자동 분배 로직 (핵심 알고리즘)

js/app.js               화면/이벤트 로직
apps-script/Code.gs     구글 시트에 붙일 백엔드 스크립트
data/길드원_명단_샘플.csv  명단 양식 예시
tests/party.test.js     파티 분배 테스트  (npm test)
```

## 🚀 빠른 시작

### 0. 바로 미리보기 (데모 모드)
`js/config.js` 의 `APPS_SCRIPT_URL` 이 비어 있으면 **데모 모드**(브라우저 저장)로 동작합니다.
로컬에서 열어 화면/기능을 바로 확인할 수 있습니다.

```bash
# 저장소 폴더에서

# 브라우저에서 http://localhost:8000 접속
```

> 데모 모드는 **본인 브라우저에만** 저장됩니다. 여러 사람이 공유하려면 아래 구글 시트 연동을 하세요.

## 🔗 구글 시트 연동 (실제 다중 사용자)

### 1. 구글 시트 만들기
새 구글 시트를 만들고 아래 **탭 3개**를 추가합니다 (탭 이름 정확히):

**① `길드원`** — 길드원 명단 (관리자가 미리 등록)

| 캐릭터명 | 클래스 |
|---------|--------|
| 아르베드 | 전사 |
| 티르코네일 | 힐러 |
| … | … |

> `data/길드원_명단_샘플.csv` 를 그대로 가져와도 됩니다.
> **클래스 표기**는 아래 계열 표를 따르세요. 표에 없는 클래스는 모두 "딜러"로 처리됩니다.

**② `설정`**

| 키 | 값 |
|------|------|
| 기본시간 | 21:00 |
| 마감시간 | 21:00 |

**③ `투표`** — 비워두세요(헤더는 스크립트가 자동 생성). 직접 만들 경우 헤더:
`주차 | 캐릭터명 | 참석여부 | 시간 | 전투력 | 업데이트시각`

### 2. Apps Script 배포
1. 시트 상단 메뉴 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 **전부 붙여넣기**
3. (권장) ⚙️ 프로젝트 설정 → 시간대 **Asia/Seoul**
4. 우상단 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 실행 권한: **나(본인)**
   - 액세스 권한: **모든 사용자**
   - **배포** 클릭 → 권한 승인
5. 표시된 **웹 앱 URL**(`https://script.google.com/macros/s/..../exec`)을 복사

### 3. 사이트에 URL 연결
`js/config.js` 를 열어 붙여넣기:

```js
APPS_SCRIPT_URL: 'https://script.google.com/macros/s/..../exec',
```

이제 사이트가 구글 시트와 실시간으로 연동됩니다. (모두가 같은 데이터를 봅니다)

> 💡 코드 수정 후 재배포할 땐 **배포 → 배포 관리 → 기존 배포 편집(연필) → 버전: 새 버전 → 배포**.
> "새 배포"를 또 만들면 URL이 바뀌니 주의하세요.

## 🌐 GitHub Pages 배포
1. 이 저장소를 GitHub에 푸시 (이미 푸시되어 있음)
2. 저장소 **Settings → Pages**
3. **Source: Deploy from a branch**, Branch: `main`(또는 배포 브랜치) `/ (root)` → Save
4. 잠시 후 `https://<사용자명>.github.io/mabinogi/` 에서 접속

## ⚙️ 자주 바꾸는 설정 (`js/config.js`)

| 항목 | 설명 |
|------|------|
| `APPS_SCRIPT_URL` | 구글 시트 웹앱 URL (비우면 데모 모드) |
| `GUILD_NAME` / `CONTENT_TITLE` | 화면 상단 제목 |
| `DEFAULT_TIME` | 정시 기준 (이 시간 참석 = "9시 참석") |
| `DEADLINE_TIME` | 자동 마감 시각 (해당 주 월요일의 이 시각 지나면 마감) |
| `PARTY_SIZE` | 파티 인원 (기본 4) |

> 시트 연동 시 `기본시간`·`마감시간`은 **시트의 `설정` 탭 값이 우선** 적용됩니다.

## 🧩 파티 분배 규칙

**계열 구분**

| 계열 | 클래스 |
|------|--------|
| 🛡 탱커 | 전사, 빙결술사, 기사 |
| 💚 힐러 | 힐러, 사제, 음유시인, 수도사 |
| ⚔ 딜러 | 그 외 전부 |

**분배 우선순위**
1. 파티당 **탱커 1 + 힐러 1** 우선 구성
2. 부족하면 **둘 중 한 계열이라도** 들어가도록
3. 그래도 모자라면 탱/힐이 **여러 파티에 분산**되도록 (한 파티에 몰리지 않게)
4. 그 위에서 **파티별 전투력 합이 비슷하도록** 균형 분배
5. 탱/힐이 없는 파티는 화면에 **`탱 없음 / 힐 없음`** 경고 표시

`전투력` 균형이나 계열을 바꾸려면 `js/party.js` 상단의 `TANK_CLASSES`/`HEAL_CLASSES` 만 수정하면 됩니다.

## ❓ 문제 해결

- **투표가 저장 안 돼요 / CORS 오류** → Apps Script 배포 시 액세스가 **"모든 사용자"** 인지 확인하세요.
- **마감 시간이 이상해요** → Apps Script 프로젝트 시간대를 **Asia/Seoul** 로 설정했는지 확인.
- **클래스가 딜러로 나와요** → 시트 `길드원` 탭의 클래스 표기가 위 계열 표와 정확히 일치하는지 확인.
- **새 주가 안 넘어가요** → "이번 주 월요일"은 자동 계산됩니다(오늘이 월요일이면 오늘, 아니면 다가오는 월요일). 주가 바뀌면 투표는 자동으로 새로 시작됩니다.
